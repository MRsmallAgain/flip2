Two things worth knowing about the mirror: it is not a stopgap — it holds the same bytes, hash-verified by downloading them back, and it is what the browser wizard always fetched from. And packages/ has no directory listing (403 by design); catalog.json is the index. CloudFront serves accept-ranges, so the 395 MB complete installer resumes rather than restarting.

Safest first install

flip2-installer-full-magisk.zip — 395,628,118 bytes, SHA-256 298b46685ed97fcad763bb2ae39ca48e58efb83b2102f1f60af0d6fce8a4317b. Flash it once in the Magisk app, then reboot.

Before any of that: full features need root/Magisk, and the wizard’s Put on phone step is still experimental — for a first install prefer the complete installer zip above. Unlocking the bootloader erases the phone. Never write super, vbmeta, system, product or the preloader, and never touch the EMMC_BOOT header. There is no verified boot on this device and no way to restore it; a backup you have not tested is not a backup. 

curl -fLO https://flip2burn.online/packages/flip2-installer-full-magisk.zip
sha256sum flip2-installer-full-magisk.zip

What is still broken

  • GitHub release binaries — gone with the account. The mirror replaces them.
  • The Forkgram fork (MRsmallAgain/TelegramAndroid) — unreachable, so republishing the patched APK is blocked. The APK itself is mirrored and installs fine; flip2 forkgram release verifies it against the catalog pin.
  • flip2 release — now publishes on GitLab, with the assets as links into this mirror rather than ~1.4 GB of uploads.

If you arrived from an old link

Everything the old release pages pointed at is on the mirror under the same filenames. catalog.json is the authoritative list — if a name is not in there, it was never published.
