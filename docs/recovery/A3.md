# A3 — device install/verify scripts

**class:** RUN  
**depends:** A2

## Human

`wizard/device/install.sh` and `verify.sh` have `# BEGIN GENERATED` / `# END GENERATED` regions filled from `pipeline/deploy/manifest.json` and `launcher-overlay/home-keys.json`. `flip2 wizard render` regenerates them; `flip2 wizard check` fails on drift. Second render produces an empty diff. Wizard push names (`forkgram.apk`, `materialfiles.apk`) match `install.sh` header comments.

## Agent

**READ:** `pipeline/deploy/manifest.json`, `wizard/device/install.sh`, `wizard/device/verify.sh`, `launcher-overlay/home-keys.json`

**WRITE:** `pipeline/wizard/render.sh`, `wizard/device/install.sh`, `wizard/device/verify.sh`, `bin/flip2`, `docs/recovery/A3.md`

**NEVER:** Open other recovery modules except router; upload zips.

### Constants

See `docs/recovery/00-router.md`.

### Steps

1. Add GENERATED markers; implement `render.sh` (`gen_install`, `gen_verify`, `wizard_incoming` short names).
2. Wire `flip2 wizard render|check`.
3. Run render twice; `diff` empty on install and verify GENERATED blocks.
4. Commit `wizard: generate install and verify from the manifest`; push `feature/rooting-slice`.

**PASS:** Second render empty diff; `flip2 wizard check` OK; install uses short incoming APK names and proper `\` continuations (no literal `\n`).

Stop. Do not open the next module.
