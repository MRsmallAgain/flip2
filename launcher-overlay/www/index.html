Menu slots 1–9

Edit slots.json in the overlay folder (package name per key, or @tools for the Tools folder).

~/.local/share/flip2/launcher-overlay/slots.json

Apply (USB adb, root for idmap):

~/.local/share/flip2/launcher-overlay/scripts/apply-slots.sh

On the phone, TCL may still let you reorder in the stock launcher settings if that menu exists — overlay only sets default order and apps.

Slot 5 also updates def_appmenu_position_five when it is a normal app package.

Homescreen soft keys

On the main workspace (not inside the Menu grid):

  • Left — Notifications (opens TCL notification panel; label notice in overlay)
  • Center — Menu (opens the 1–9 app grid from slots.json; label menu)
  • Right — Shortcuts (launches app from Settings.Global keyshortcut_rightkey; label shortcuts)

Relabel left/center/right: edit notice, menu, shortcuts in res/values/strings.xml, then run apply-slots.sh.

Change which app the right key opens: edit home-keys.json, then run apply-home-keys.sh.

Value format: Label-package-componentActivity with hyphens.

Menu grid — edit slots

The overlay cannot add long-press or a new Edit soft key inside Launcher3 (that needs launcher APK changes). Stock menu grid:

  • Center soft key often shows select (overlay can relabel to “Edit” — behavior unchanged).
  • Long-press on an icon may start drag-to-home; order is not saved back into allapp_list / your overlay.

On phone (PC running editor + adb reverse tcp:8765 tcp:8765): /edit — pick slot 1–9, app, then Apply on phone.

On PC: edit-slot.sh 5 com.android.settings or edit slots.json + apply-slots.sh.
